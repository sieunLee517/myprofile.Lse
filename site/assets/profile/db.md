### 학습 목적
데이터베이스에서 조인, 뷰, 서브쿼리, 인덱스 등의 활용 방식에 따른 성능 차이와 동작 원리를 분석하는 것입니다.  

### 역할 
학생 테이블(hw4_student)과 수강 테이블(hw4_takes)의 데이터를 연동하여 다양한 SQL 쿼리와 뷰를 작성하고 인덱스 적용 전후의 실행 성능을 비교·검증했습니다.  

### 과정
내부 조인, 뷰 생성, 서브쿼리 활용, 그리고 인덱스(idx_student_id) 추가에 따른 쿼리 작성과 반복 실행 결과를 측정하여 소요 시간을 분석했습니다.   

### 결과
서브쿼리를 사용할 때가 내부 조인보다 약 20배 빨랐으며, 인덱스를 적용한 경우 조인 연산 속도가 약 60배 단축되는 등의 유의미한 성능 향상 효과를 확인했습니다.
